# Лицензии сторонних компонентов

Все компоненты — с открытыми лицензиями; облачные сервисы и внешние API в решении не используются (модели и кэш
распознавания — внутри образов).

## Python (ML-часть и воркер)

| Компонент | Версия | Лицензия | Где используется |
|---|---|---|---|
| PyMuPDF | 1.28 | **AGPL-3.0** (или коммерческая Artifex) | чтение PDF, текстовый слой, слои CAD, картинки страниц, протокол PDF |
| python-docx | 1.2 | MIT | протокол DOCX |
| jsonschema | 4.x | MIT | проверка ответа по схеме организаторов |
| NumPy | 2.x | BSD-3-Clause | геометрия чертежей, вырезки страниц |
| OpenCV (opencv-python-headless) | 4.x | Apache-2.0 | обработка изображений для OCR |
| pika | 1.3 | BSD-3-Clause | клиент RabbitMQ в воркере |
| EasyOCR | 1.7 | Apache-2.0 | OCR надписей на чертежах (образ для стенда жюри) |
| PyTorch | 2.x | BSD-3-Clause | движок EasyOCR (образ для стенда жюри) |
| PaddleOCR / PaddlePaddle | 3.x | Apache-2.0 | распознавание сканов ИД — выполнено заранее в Colab, в образ входит только результат (кэш) |
| openpyxl | 3.1 | MIT | чтение матрицы параметров (xlsx) в служебных скриптах |
| Python | 3.12 | PSF-2.0 | — |

**Про AGPL-3.0 (PyMuPDF).** Лицензия требует открыть исходный код программы, которая использует библиотеку, в том
числе когда программа доступна по сети. Репозиторий решения публичный, исходный код открыт целиком — условие
выполняется. Для закрытого внедрения нужна коммерческая лицензия Artifex либо замена на библиотеку с разрешительной
лицензией (pypdfium2 — Apache-2.0 / BSD, pdfplumber — MIT) — это отдельная работа: слои CAD и векторная графика
чертежей берутся именно из PyMuPDF.

## Данные

Документы объектов, матрица параметров и схема ответа предоставлены организаторами хакатона и в репозиторий не
входят, кроме матрицы 132 параметров и схемы ответа (`backend/reference/`) — это приложения к ТЗ, без них сервис не
построит протокол для загруженного объекта. Тестовая разметка организаторов не используется.
