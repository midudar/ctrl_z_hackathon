# ctrl_z_hackathon
Гит-репо команды на хакатон. Делаем ИИ-сервис отслеживания и анализа изменений между стадиями проектирования, а также контроля исполнительной документации

## ML-часть — папка [`ml-service/`](ml-service/)

Сверка ПД → РД → ИД по матрице 132 параметров: одна команда `python -m ml.run <объект>` (из папки `ml-service/`) даёт
файл ответа со всеми параметрами, значениями на стадиях и доказательствами (файл, страница, рамка фрагмента) и отчёт о
целостности комплекта. Есть Docker-образ для стенда жюри.

- [ml-service/README.md](ml-service/README.md) — запуск, вход, поля ответа, чего нет в репозитории;
- [Документ для разработчиков](ml-service/docs/Инспектор_ИИ_ML_для_разработчиков.md) — полный контракт интеграции: вход,
  запуск, Docker, формат ответа, интерфейс, протокол по Приложению 2;
- [Всё для презентации](ml-service/docs/Инспектор_ИИ_ML_для_презентации.md) — цифры, примеры, слайды, ответы на вопросы жюри;
- [ml-service/CLAUDE.md](ml-service/CLAUDE.md) — подробный журнал ML: данные, правила, замеры, открытые вопросы.

Кэш распознанных страниц и модели (`inspector_ml_assets.zip`), а также слайды (`inspector_ml_slides.zip`) — в GitHub
Releases: в git их нет, без первого архива Docker-образ не соберётся.
